# SVN 极速搜索 (Spotlight 悬浮快捷版) 使用说明书

## 一、 软件概述

本软件采用类似 **macOS Spotlight / Listary** 的极简居中悬浮胶囊交互，专为工程师日常高频查找 SVN 文件而设计：

1. **完全静默常驻后台**：
   - 双击打开后程序直接常驻屏幕右下角系统托盘，不弹大窗口打扰当前工作。
2. **全局快捷键随叫随到**：
   - 在任何软件（Altium Designer、CAD、VS Code、浏览器、Office）下按下全局快捷键，即可瞬间在屏幕正中呼出极速搜索框。
3. **三大部门一键切换**：
   - 搜索框右侧内置【💻 电子】、【📐 结构】、【🛠 工艺】快捷切换胶囊，毫秒级切换内存索引。
4. **内置全量离线索引**：
   - 支持开箱即用，无需初次拉取等待。
5. **EDA、CAD 与多格式深度支持**：
   - 全面收录并支持 `.csv`, `.xlsm`, `.dwg`, `.dxf`, `.SchDoc`, `.Sch`, `.SchLib`, `.pcb`, `.PcbLib`, `.PrjPcb`, `.xmind`, `.mpp` 等；
   - 搜索栏提供【🔄 增量更新按键】，轻量按需一键检查并同步远程最新提交；
   - 搜索栏提供【后缀/类型筛选胶囊】，一键直选【⚡ 原理图/PCB】、【📐 CAD图纸】、【🧠 思维导图】、【📊 表格/Excel】等；
   - 搜索框内亦直接支持语法糖如 `ext:dwg`、`ext:eda`、`ext:pcb`、`ext:xmind` 或 `*.prjpcb`。
6. **双击直达 Repo-Browser**：
   - 找到目标文件后，回车或双击直接调起 TortoiseSVN 版本库浏览器精准定位到所在目录，并自动将完整 URL 复制到剪贴板，同时搜索框自动隐藏。

## 二、 快捷键操作与交互流程

1. **呼出 / 收起搜索框**：
   - 默认全局热键：`Alt + Q`
   - 唤醒后光标已自动聚焦于输入框，直接打字即可；
   - 再次按下 `Alt + Q` 或在输入框为空时按 `Esc`，即可瞬间收起。
2. **快速检索与自适应展开**：
   - 输入关键字后按下 `Enter`，搜索框自适应平滑向下展开结果表格；
   - 检索响应时间仅需几毫秒，支持拼音、文件后缀或多关键词模糊匹配。
3. **键盘上下穿透与定位**：
   - 结果出现后，按键盘方向键 `↓` 或 `↑` 直接在结果列表中选择条目；
   - 选中条目后按 `Enter` 或直接鼠标双击，立即调起 TortoiseSVN 并在 Repo-Browser 中打开所在目录，并自动收起搜索框；
   - 若想重新修改搜索词，直接按 `Esc` 键，光标自动跳回输入框并全选文字。
4. **失焦自动收起**：
   - 当呼出搜索框后，若鼠标点击了其他应用程序窗口或桌面空白处，搜索框将自动轻量隐藏，完全不干扰正常工作。

## 三、 部门仓库与后缀切换

搜索条右侧内嵌分段式胶囊控件，可随时切换：
- **范围切换**：`[📄 搜文件名]`、`[📁 搜所在路径]`、`[🌐 全路径匹配]`
- **后缀筛选**：`[🏷 全部后缀]`、`[⚡ 原理图/PCB]`、`[📐 CAD图纸]`、`[🧠 思维导图]`、`[📊 项目计划]` 等
- **部门仓库**：
  - `[💻 电子]`：电子中心主干
  - `[📐 结构]`：结构设计仓库
  - `[🛠 工艺]`：工艺设计仓库

## 四、 系统托盘与个性化设置

鼠标右键点击屏幕右下角的托盘图标，可呼出功能菜单：
1. **🔍 唤醒搜索**：手动呼出居中搜索框（也可直接鼠标左键单击托盘图标唤醒）。
2. **⚙ 快捷键设置**：
   - 若默认的 `Alt + Q` 与其他专业软件快捷键有冲突，可随时在此窗口选择或更改热键预设（如 `Ctrl+Shift+F`, `Ctrl+Shift+Space`, `Alt+S` 等），即时生效并持久化保存。
3. **🚀 开机自启动**：
   - 勾选后，开机登录 Windows 将自动在后台常驻托盘待命。
4. **✕ 退出程序**：彻底关闭后台常驻进程。

## 五、 常见问题解答 (FAQ)

- **Q: 双击运行时为什么屏幕中间没有弹出主窗口？**  
  **A:** 这是 Spotlight 悬浮版的正常设计。双击运行后程序已静默常驻在屏幕右下角托盘中，并弹出就绪提示气泡。按下 `Alt + Q` 即可随时呼出。

- **Q: 多次双击 EXE 会重复运行多开吗？**  
  **A:** 不会。软件内置单实例互斥锁，重复运行时只会自动呼出已有的搜索框，杜绝重复进程或热键冲突。

- **Q: 双击为什么没有打开 TortoiseSVN？**  
  **A:** 请确认已安装 TortoiseSVN 客户端（默认路径：`C:\Program Files\TortoiseSVN\bin\TortoiseProc.exe`）。若未安装，程序会自动降级为调用系统默认浏览器打开 Web 访问页面。
